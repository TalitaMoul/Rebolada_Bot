#Rebolada Bot 
Bot para Discord desenvolvido em Python, criado para automatizar a votação de times em partidas 5x5 dentro de servidores.
🔗 Repositório

## Funcionalidades

- Geração automática de enquetes para votação de times
- Suporte a partidas 5x5 jogadores
- Automação de um processo que antes era feito manualmente no servidor


## Tecnologias

- **Python** — linguagem principal do bot
**Discord API (discord.py)** — integração com a plataforma Discord para leitura de comandos e envio de mensagens


## Como rodar localmente
#### ***bash#*** Clone o repositório
`git clone https://github.com/TalitaMoul/Rebolada_Bot.git`

## Acesse a pasta
`cd Rebolada_Bot`

## Instale as dependências
`pip install -r requirements.txt`

## Configure o token do bot no arquivo .env
`DISCORD_TOKEN=seu_token_aqui`

## Execute o bot
`python bot.py`

***Para obter um token, acesse o Discord Developer Portal e crie uma aplicação.***


## Aprendizados
Projeto desenvolvido para praticar automação com Python e integração com APIs externas, aplicando conceitos de eventos, comandos e manipulação de dados em tempo real via Discord API.
